Clínica Veterinária Pata-Amiga

O projeto para uma clinica fictícia focado paras os funcionários da clinica com funcionalidades relacionadas a cadastro, gestão de estoque, consultas, etc.

O programa atualmente possui:
Tela de login funcional
Tela de cadastro funcional
Tela de estoque funcional
Sistema gerenciamento de cargos

Funcionalidades futuras:
Cadastro de Pets 
Sistema de notificação sobre a quantidade de itens 

Ferramentas:
VSCode
Javascript
HTML
CSS
